# OCTera

Интеллектуальная медицинская AI-платформа для автоматического анализа оптической когерентной томографии (ОКТ) сетчатки глаза.

Платформа предназначена для помощи врачам-офтальмологам в диагностике заболеваний глаз путем анализа медицинских изображений с использованием современных технологий компьютерного зрения и глубокого обучения.

OCTera не заменяет врача, а выступает в роли интеллектуального ассистента, который за несколько секунд анализирует ОКТ-снимок, обнаруживает патологические изменения, оценивает вероятность различных заболеваний, выделяет проблемные области и формирует предварительное медицинское заключение.

## Текущий этап продукта

Реализованный MVP — **self-service сервис** по модели ChatGPT/Claude: любой человек сам регистрируется и загружает собственные ОКТ-снимки, без понятия "врач ведёт карточки пациентов". Монетизация в этой модели — будущие подписки (см. «Бизнес-модель» ниже).

Клиническая/B2B-модель (несколько пациентов на одного врача, история и динамика по пациенту, PACS-интеграции, роли в клинике) — описана в разделах ниже как долгосрочное направление, но пока не реализована в продукте; технически для неё уже есть задел (в БД учётная запись пользователя 1-в-1 связана с профилем пациента, откуда при необходимости можно вырастить полноценную многопользовательскую модель).

## Разработка

Репозиторий — монорепо из двух частей:

- `backend/` — FastAPI-сервис: REST API, аутентификация, хранение исследований, оркестрация AI-пайплайна (`app/services/pipeline.py`).
  - **Quality-check** (`app/services/quality_check.py`) — реальная статистика по загруженному изображению: разрешение, резкость (дисперсия Лапласиана), экспозиция.
  - **Сегментация** (`app/services/segmentation.py`) — реальный сигнал-процессинг по пикселям снимка: тепловая карта — это карта градиента яркости (границы структур), толщина слоёв оценивается детекцией пиков на профиле яркости по глубине скана (классический A-scan подход, предшественник deep learning сегментации). Не обучаемая модель и не per-pixel сегментация — честная эвристика на реальных данных снимка, а не случайные числа. Пересчёт в микроны использует условный коэффициент (нет калибровки скана) — абсолютные значения толщины иллюстративные. Точка, куда подключается обученная U-Net/nnU-Net при появлении размеченного датасета.
  - **Карта патологий** (та же `segmentation.py`) — алгоритмически находит гипорефлективные (тёмные) локализованные зоны внутри слоёв сетчатки — классический прокси для жидкости/кист/отслойки на ОКТ (они оптически "пустые", т.е. тёмные). Это простой heuristic (локальный порог по яркости + фильтр по форме пятна), **не диагноз и не классификатор типа находки** — для точного разделения "киста vs жидкость vs артефакт" нужна модель, обученная на попиксельной разметке, которой пока нет. В интерфейсе и в тексте заключения явно помечено как "требует проверки врачом".
  - **Диагностика** (`app/services/diagnosis.py`) — реально обученный классификатор из `app/ml/` (см. ниже).
  - **Генератор заключения** (`app/services/report_generator.py`) — шаблонная сборка текста из структурированных находок, включая предупреждение при низкой уверенности модели (`LOW_CONFIDENCE_THRESHOLD`); описан как точка для подключения LLM (например, через Ollama — см. обсуждение ниже), но сама LLM пока не подключена (её веса тоже нужно откуда-то скачать, а публичные реестры моделей недоступны из этой песочницы).
- `frontend/` — личный кабинет на Next.js (App Router, TypeScript): вход/регистрация, прямая загрузка ОКТ-снимка, список своих исследований, страница результата (снимок, карта, толщина слоёв, вероятности диагнозов, текст заключения). Каждый пользователь видит только свои исследования (проверка владения на бэкенде, см. `app/api/deps.py:get_current_patient`).

### ML-классификатор диагнозов (`backend/app/ml/`)

Модель обучена на **реальных ОКТ-снимках пациентов**, а не на синтетике. Датасет: [OCT-AND-EYE-FUNDUS-DATASET](https://github.com/Traslational-Visual-Health-Laboratory/OCT-AND-EYE-FUNDUS-DATASET) (Hughes Cano, Olivares Pinto & Thébault; CONACYT/UNAM/IMO/APEC/INDEREB) — 1113 ОКТ-снимков с диагнозом диабетического макулярного отёка (DME), установленным врачами-офтальмологами. Классификация бинарная: `NORMAL` / `DME` — датасет не размечает другие патологии (CNV, друзы и т.п.), поэтому модель пока предсказывает только их.

`app/ml/train.py` подбирает лучший классификатор кросс-валидацией (сбалансированная точность, т.к. DME — миноритарный класс: 167 из 1113) среди нескольких кандидатов (MLP разных размеров, RandomForest, SVM с `class_weight="balanced"`) поверх признаков уменьшенного до 48×48 изображения.

**Текущие метрики** (см. полностью в `app/ml/artifacts/metrics.json`): held-out test accuracy 84.8%, для класса DME precision 0.49 / recall 0.67 — модель находит две трети случаев отёка, но почти половина её "тревог" — ложные (ожидаемо для простого pixel+shallow-classifier подхода на ~1100 снимках; полноценная CNN на большем датасете дала бы существенно лучший результат). Это реальная, но не клинически валидированная модель — она демонстрирует механизм, а не готова к диагностическому использованию.

Переобучить (или обучить на любом другом датасете с такой же структурой) можно так:

```bash
git clone https://github.com/Traslational-Visual-Health-Laboratory/OCT-AND-EYE-FUNDUS-DATASET.git
cd backend
python -m app.ml.train --data-dir /path/to/OCT-AND-EYE-FUNDUS-DATASET
```

Без `--data-dir` скрипт обучается на процедурно сгенерированной синтетике (`app/ml/synthetic_dataset.py`) — это smoke-test пайплайна, а не рабочая модель; полезно только чтобы быстро проверить, что код обучения/инференса не сломан.

Скрипт сохранит новый чекпоинт в `app/ml/artifacts/oct_classifier.joblib`; перезапустите backend, чтобы он подхватил новые веса (инференс кэширует загруженную модель в памяти процесса).

### Запуск через Docker Compose

```bash
cp backend/.env.example backend/.env
docker compose up --build
```

- Бэкенд: http://localhost:8000 (документация API — `/docs`)
- Фронтенд: http://localhost:3000

### Локальный запуск без Docker

Бэкенд (Python 3.12+):

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

По умолчанию используется SQLite (`backend/octera.db`), для Postgres задайте `DATABASE_URL` в `backend/.env`.

Тесты бэкенда:

```bash
cd backend
pytest
```

Фронтенд (Node.js 20+):

```bash
cd frontend
cp .env.local.example .env.local
npm install
npm run dev
```

Тесты фронтенда (Vitest + Testing Library):

```bash
cd frontend
npm test
```

### CI

`.github/workflows/ci.yml` на каждый push/PR гоняет `pytest` для бэкенда и `npm test` + `npm run build` для фронтенда.

## Миссия

Сделать высокоточную диагностику заболеваний сетчатки доступной каждой клинике независимо от ее размера, сократить время анализа исследований и повысить качество медицинской помощи за счет современных технологий искусственного интеллекта.

## Проблема

Сегодня большинство исследований ОКТ анализируются врачом вручную. Этот процесс имеет несколько недостатков:

- высокая нагрузка на специалистов;
- человеческий фактор;
- различия в опыте врачей;
- длительное время подготовки заключения;
- ограниченный доступ к опытным офтальмологам в небольших городах.

При увеличении количества исследований растет вероятность пропустить ранние признаки заболевания.

## Решение

OCTera автоматически анализирует медицинские изображения и помогает врачу принимать решения.

После загрузки ОКТ-снимка система:

1. Проверяет качество изображения.
2. Выполняет предварительную обработку данных.
3. Анализирует анатомические структуры сетчатки.
4. Выполняет сегментацию всех основных слоев.
5. Находит патологические изменения.
6. Определяет наиболее вероятные заболевания.
7. Рассчитывает вероятность каждого диагноза.
8. Строит карту обнаруженных патологий.
9. Генерирует подробное медицинское заключение.
10. Сохраняет результаты исследования.

Полный анализ занимает несколько секунд.

## Основные возможности

### Автоматический анализ ОКТ

Система определяет:

- возрастные изменения;
- макулярный отек;
- диабетический макулярный отек;
- возрастную макулярную дегенерацию;
- глаукому;
- эпиретинальную мембрану;
- серозную отслойку;
- нарушения структуры сетчатки;
- атрофические изменения;
- другие патологии.

### Сегментация

Нейросеть автоматически выделяет:

- внутренние и наружные слои сетчатки;
- область макулы;
- жидкость;
- кисты;
- зоны повреждений;
- патологические образования.

Полученная карта помогает врачу быстрее интерпретировать результаты исследования.

### AI-заключение

После анализа система автоматически формирует:

- описание исследования;
- найденные изменения;
- предполагаемый диагноз;
- уровень уверенности модели;
- рекомендации по дальнейшему обследованию.

Заключение может использоваться как предварительная версия для врача.

### Визуализация

Пользователь получает:

- исходное изображение;
- тепловую карту внимания модели;
- карту сегментации;
- выделенные патологические области;
- показатели толщины слоев;
- вероятности заболеваний.

### API

Платформа предоставляет REST API для интеграции с:

- медицинскими информационными системами;
- PACS;
- лабораторными системами;
- облачными сервисами;
- мобильными приложениями.

### История исследований

Для каждого исследования сохраняются изображения, результаты анализа и диагнозы — это уже реализовано (список своих исследований в личном кабинете). Сравнение динамики между исследованиями одного пользователя во времени — в планах (см. «Текущий этап продукта»).

## Архитектура

Платформа состоит из нескольких AI-модулей.

**Модуль проверки качества** — определяет достаточность качества изображения, наличие шумов, размытость, артефакты, ошибки сканирования.

**Модуль сегментации** — использует современные архитектуры компьютерного зрения для выделения анатомических структур глаза.

**Модуль диагностики** — на основе результатов сегментации определяет наличие заболеваний и рассчитывает вероятность каждого диагноза.

**Генератор медицинских заключений** — использует языковую модель для формирования структурированного текста заключения на русском языке.

**Модуль аналитики** — собирает статистику исследований, оценивает качество работы модели и отслеживает изменения ее эффективности.

## Безопасность

OCTera разрабатывается с учетом требований медицинских информационных систем. Предусмотрены:

- шифрование данных;
- разграничение прав доступа;
- журналирование действий пользователей;
- анонимизация персональных данных;
- защищенная передача информации;
- резервное копирование;
- аудит безопасности.

## Бизнес-модель

Планируется несколько вариантов использования продукта.

- **Self-service подписка** (ближайший этап) — физлицо регистрируется само и платит подписку за доступ к анализу собственных снимков, по аналогии с ChatGPT/Claude.
- **SaaS** — клиника оплачивает подписку и получает доступ к облачной платформе.
- **Enterprise** — развертывание системы на инфраструктуре медицинской организации.
- **API** — оплата за количество выполненных исследований через API.
- **Research** — лицензии для университетов и научных организаций.

## Долгосрочная цель

Создать универсальную AI-платформу для офтальмологии, которая станет стандартом автоматического анализа ОКТ-исследований, поможет врачам принимать более точные решения, сократит время диагностики и повысит доступность качественной медицинской помощи.
